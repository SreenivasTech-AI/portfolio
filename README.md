## 🚀 How to Run Locally

### Option 1: Native Node Server
```bash
cd C:\portfolio
npm start
# or: node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Direct Browser Launch
Simply double-click `index.html` to open it in Chrome, Edge, Brave, or Firefox. No build steps or node installs required!

## 📸 How to Add Your Personal Photo

1. Place your photo (PNG, JPG, or WebP) inside the `assets/` folder, for example `assets/my-photo.jpg`.
2. Open [`index.html`](file:///c:/portfolio/index.html) and search for `assets/profile-placeholder.svg`.
3. Change it to `assets/my-photo.jpg`:
   ```html
   <img src="assets/my-photo.jpg" alt="Sreenivasulu N - AI & ML Engineer">
   ```
